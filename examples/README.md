# PR Newswire Scraper API – code examples

Examples for every PR Newswire endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/article.sh`](curl/article.sh) | `bash article.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/article.php`](php/article.php) | `php article.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Article.cs`](csharp/Article.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/article.go`](go/article.go) | `go run article.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ArticleExample.java`](java/ArticleExample.java) | `java ArticleExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/article.rb`](ruby/article.rb) | `ruby article.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/article.mjs`](nodejs/article.mjs) | `node article.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
